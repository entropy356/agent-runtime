# Emotion–Memory Space Measurement

测量对象：`demos/demo1-emotion-memory` 在真实模型下跑 9 轮对话后的内部状态。
日期：2026-10-31。地点：沙箱，commit `4e4de38` + 本地未提交的 provider 拆分改动。

---

## 1. 被测系统

每轮 `step(text)` 做四件事：

1. 用嵌入模型编码输入，与库内记忆算余弦，得 `rel`
2. 情绪门控：`r = σ(4·s)`，`s = cos(E, affect_i)`；关闭时 `r = 0.5`
3. 排序：`score = rel · r · w`，`w = σ(3·EᵀA)` 为写入时固化的常数，取 top-3
4. LLM 输出 `{answer, appraisal, used_memory_ids, memories}`，`appraisal` 文本再嵌入后按 `E ← 0.85·E + 0.15·unit(appraisal)` 更新情绪，然后写入新记忆

配置：

| 项 | 值 |
|---|---|
| 认知模型 | `deepseek/deepseek-v4.1-flash`（api.qnaigc.com） |
| 嵌入模型 | `gemini-embedding-001`，768 维，经 HTTP 代理 |
| taskType | 记忆 `RETRIEVAL_DOCUMENT`，查询 `RETRIEVAL_QUERY` |
| ρ | 0.85 |
| top-k | 3 |

## 3. 记忆空间几何

19 条向量均为单位向量。

| 指标 | 值 |
|---|---|
| 两两余弦 均值 / 中位 | 0.739 / 0.732 |
| 两两余弦 区间 | 0.612 – 0.898 |
| 19 条向量均值长度 | **0.868** |
| 解释方差 前 10 主成分 | 82% |
| 达到 90% 方差所需成分 | **13**（共 768 维） |

均值长度 0.868 是关键：独立同分布时该值应约为 `1/√19 ≈ 0.23`。0.868 意味着约 **87% 的能量位于一个所有记忆共享的方向**上。

减去该公共分量后重新计算余弦：

| 分组 | 组内均值 |
|---|---|
| 项目/实验 | +0.205 |
| AI 身份/连续性 | +0.080 |
| 收尾/重启 | +0.146 |

| 组间 | 均值 |
|---|---|
| 项目 ↔ 身份 | −0.182 |
| 项目 ↔ 收尾 | −0.189 |
| 身份 ↔ 收尾 | −0.039 |

原始余弦（均值 0.739）下三组几乎不可分；中心化后组内正、组间负，话题结构才出现。

## 4. 情绪空间

| 指标 | 值 |
|---|---|
| 维度 | 768 |
| 当前范数 | 0.864（自第 1 轮 1.000 单调下降） |
| 相邻轮余弦 | 0.9929 – 0.9956 |
| 单轮位移 L2 | 0.084 – 0.120 |
| 9 轮净位移 | 0.397 |
| 9 轮路径长度 | 0.789 |
| 直线度（净位移/路径） | **0.50** |
| 首末余弦 / 夹角 | 0.919 / 23.2° |

直线度 0.50 表示轨迹在绕行而非单向漂移。范数单调收缩来自凸组合本身，与方向变化叠加。

情绪向量与记忆空间的关系：

| 指标 | 值 |
|---|---|
| cos(E, 记忆均值向量 μ) | **0.851** |
| cos(E, 各记忆) 区间 | 0.688 – 0.808 |
| 该区间极差 | 0.121 |
| 中心化后 cos(E−μ, v−μ) 区间 | −0.226 – +0.262 |
| 中心化后标准差 | 0.115 |

即情绪向量本身也以 85% 的权重落在同一条公共方向上，它与 19 条记忆的区分度极差仅 0.121。

## 5. 门控的实际数值域

统计 9 轮全部 top-3 命中样本（n = 21）：

| 因子 | 区间 | 跨度 |
|---|---|---|
| `rel` | 0.609 – 0.778 | 0.169 |
| `r = σ(4s)` | 0.927 – 0.961 | **0.034** |
| `w = σ(3·EᵀA)` | 0.870 – 0.917 | **0.046** |
| `score` | 0.531 – 0.668 | 0.137 |

`r` 与 `w` 已进入 sigmoid 饱和区，各自的可变范围只有 `rel` 的 1/5 与 1/4。排序结果主要由 `rel` 决定，情绪门控只起微调作用。

对照：离线模式的哈希 bigram 向量相似度落在 0.0x 量级，恰好位于 sigmoid 线性区，因此门控在离线 demo 中看起来有效；换成语义嵌入后该机制退化。**离线 demo 验证的是链路，不是机制。**

## 6. 中心化对照实验

对每一轮，用"当时库内已有的记忆"重放（避免使用未来记忆），比较：

- 原始：`rel = cos(q, v)`
- 中心化：`rel = cos(q−μ, (v−μ)/‖v−μ‖)`，μ 为该轮库均值

n = 7（第 2 轮库仅 1 条、第 1 轮库为空，排除）。

| 轮 | 库大小 | 原始 top1 | 中心化 top1 | 原始 top1−第4 | 中心化 top1−第4 |
|---|---|---|---|---|---|
| 3 | 4 | #3 | #3 | +0.169 | +0.630 |
| 4 | 7 | #6 | #6 | +0.052 | +0.100 |
| 5 | 10 | #1 | **#9** | +0.016 | +0.142 |
| 6 | 12 | #11 | #11 | +0.051 | +0.128 |
| 7 | 14 | #7 | #7 | +0.050 | +0.087 |
| 8 | 15 | #13 | **#14** | +0.060 | +0.192 |
| 9 | 17 | #17 | #17 | +0.079 | +0.280 |

汇总：

| 指标 | 原始 | 中心化 | 倍数 |
|---|---|---|---|
| `rel` 标准差（每轮平均） | 0.0413 | 0.1394 | ×3.4 |
| top1 与第 4 名差距 | 0.016 – 0.169 | 0.087 – 0.630 | — |
| top1 改变 | — | 2/7 | — |

第 5 轮输入为「你会怎么描述你自己？是这套 runtime 里的一段认知过程，还是背后那个模型」，中心化后 top1 从 #1（用户自称熵）变为 #9（AI 承认无法自证对错），可视为改善；第 8 轮 #13→#14 两者语义相邻，无法判定优劣。

注意：中心化不改变多数排序，改变的是**分数间距**。原始间距 0.016–0.079 与 `r`、`w` 的跨度同量级，意味着门控的微小扰动即可翻转排序；中心化后间距提升到 0.087–0.630，排序对门控噪声不敏感。

## 7. 复现性核对

用同一批 query 重新嵌入并对当时库重放 `rel`：

| 项 | 结果 |
|---|---|
| `rel` 数值逐条复现 | 8/8 |
| top1 一致 | 7/8 |
| 唯一差异（第 4 轮） | 系统 top1 #7，重放 #6；`rel` 分别为 0.646 / 0.663，但 #7 的 `r·w` 更高，系统按 `score` 排序正确 |

结论：嵌入与检索链路可离线复现，差异仅来自 `score` 加权而非随机性。

## 8. 复现方法

```bash
export AGENT_CHAT_BASE=...   # OpenAI 兼容 /v1
export AGENT_CHAT_MODEL=deepseek/deepseek-v4.1-flash
export AGENT_EMBED_PROTOCOL=gemini
export AGENT_EMBED_MODEL=gemini-embedding-001
export AGENT_EMBED_DIMENSIONS=768
python -m agent_runtime --mode api --db data/x.sqlite3 step "..."
python -m agent_runtime --mode api --db data/x.sqlite3 state > state.json
```

`state.json` 含 `state.emotion`、`state.memories[].vector/affect/write_strength`、`traces[].retrieval`，本文全部指标可由该文件直接计算。

## 9. 局限

- 单次会话、19 条记忆、无人工相关度标注，**无法判断中心化后的 top1 变化是改善还是退化**，只能确定分数间距变大。
- 中心化使用当前库均值，库增长时 μ 漂移；工程上需固定 μ 或定期重算。
- 公共分量强度是否 Gemini 特有，未与其他嵌入模型对比。
- 门控饱和由 `σ(4s)`、`σ(3EᵀA)` 的常数与嵌入分布共同决定，换模型后需重新标定。
- 第 1 轮情绪向量由首次认知直接初始化，无零基线，因此"范数从 1.000 开始"是该实现的选择，不是普遍性质。
