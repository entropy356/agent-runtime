让状态随交互延续
输入 → 检索 → 认知 → 统一更新。完整聊天记录不会送入模型。模型可以要求再检索一次，用自己写的查询换更多记忆。
使用次数以认知结果显式引用的 ID 为代理；不代表能测量模型内部的真实使用。
最近运行记录
这是观察日志，不参与认知。恢复快照后，日志仍保留，因此轮次可能重复。

   
每条记忆独立存在
引用频率只做观测，不参与排序。被替代的记忆不留在运行时，也不会被再次检索或送入模型。
替代日志（调试）
仅用于核对哪条记忆在什么时候被谁取代；不属于 Agent 的状态。
